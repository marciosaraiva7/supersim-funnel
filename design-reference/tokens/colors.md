# Tokens — Cores

Extraídos do HTML de referência (`/caps/`, `/inicio/`, `/2/`).

## Funil Objetivo (`/caps`)

| Token | Valor | Uso |
|-------|-------|-----|
| `--orange` | `#FF7A1E` | Accent primary, progress, card selecionado |
| `--orange-deep` | `#F0630A` | Gradiente CTA, borda selecionada |
| `--orange-soft` | `#FFF1E4` | Blob decorativo |
| `--ink` | `#1C1B1A` | Texto principal |
| `--ink-soft` | `#6B6864` | Texto secundário, trust line |
| `--line` | `#ECE7E1` | Bordas, CTA disabled |
| `--bg` | `#FFFDF9` | Background página |
| `--green` | `#2FAE7E` | Checkmark trust line |
